## Agent skills

### Issue tracker

Issues are tracked in this repository’s GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The default Matt Pocock triage label vocabulary is used. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain documentation layout. See `docs/agents/domain.md`.

### Course output

Store each Course in its own `output/<course-slug>/` directory. Keep that
Course's JSON files, Course Package, and other generated artifacts together in
the same directory; the `output/` root contains only Course directories.
